# 引力弹道解谜 · 关卡设计梳理

> 单文件 Web MVP：`index.html`（零依赖，浏览器/手机均可拖拽游玩）。
> 物理：固定步长半隐式欧拉、确定性；黑洞成对当虫洞（进一个→从另一个沿原速度方向射出，速度向量完整保留）。
> 数值（`G`/`mu`/`V0_MAX`/卫星 `omega`/黑洞 `mu` 等）均为 `[PLACEHOLDER]`，待 playtest 调参。

## 设计约束（已 node 校验全部满足）
1. **行星⇔卫星逐体共存**：每颗行星各带一颗卫星（planet 数 = satellite 数）；无行星则无卫星。
2. **每关元素签名(类型:数量)唯一**：18 关两两不同。
3. **P3 无直线通关**：含实心天体(行星/恒星)的关，直线射击必被其挡住；纯虫洞关(L13)以「必经虫洞重定向」替代。
4. **难度序**：恒星(star) < 行星(planet，必带卫星)；黑洞作横向机制叠加；章节内由简到难。
5. **黑洞配对提示用「颜色+形状」**，不使用连线：每对共享一组配色/形状（青=圆 / 粉=菱形 / 琥珀=三角 / 绿=方），画在事件视界中心。

## 第 5 章「两队黑洞」设计要点（本次新增）
- 从原「L13 单关 blackhole×4」扩展为 **6 关系列(L13–L18)**，按用户要求"涉及两对黑洞的一系列关卡，对应叠加恒星/行星/卫星"。
- 难度递进：纯虫洞 → +恒星 → +单行星卫星 → +双行星卫星 → +四元素 → 全元素 Boss。
- **配对提示改为颜色+形状**（不再用连线）：每对黑洞共享一组颜色与中心形状，玩家一眼区分哪两个是一对（见上表约束 5 与游戏内渲染）。

## 待 playtest 调参清单（[PLACEHOLDER]）
- **L13 纯两队虫洞关**：无实心体，路由靠"重力弯曲+虫洞链式重定向"。仅逻辑验证可通，**实机可能需调两对黑洞坐标**把可行链做出来。
- **L14–L18**：恒星/行星已保证直线被挡（P3），但虫洞出口是否顺手、能否稳通需试。
- 卫星公转速度 `omega`、黑洞 `mu`、各关目标半径：按手感松紧调。
- 徽章阈值 `score≤4 金 / ≤8 银 / 否则 铜` 是否过松过紧。

## 实现备忘
- 配对配色：`PAIR_PALETTE` / `PAIR_SHAPES` 常量；`assignPairStyles()` 在 `loadLevel` 时为每对黑洞赋值 `_color`/`_shape`；`drawBody` 黑洞分支用 `_color` 画吸积环/中心字形（菱形/三角/方/圆），`hexA()` 转 rgba。
- 发射台双状态：`drawLauncher` 按 `phase` 切换（aim=青蓝发光脉动，flying/won=暗淡灰蓝）。
